# Travel Expenses belong to an Approved Travel Request, never stand alone

Many expense systems let an Employee claim any receipt on its own and attach it to a trip only if they choose to. We don't. Every Travel Expense belongs to exactly one Travel Request, and only once that Travel Request is Approved. The Manager agrees to the travel before any money is spent, and every cost is traced through the Travel Request's Assignment to a Project and Client. As a result, a one-off cost with no travel, such as a single taxi to a Client, can't be claimed in the HR system. Expenses stay claimable if the Travel Request is later Cancelled, so money already spent on approved travel, such as a non-refundable flight, is still paid back. Don't add standalone expenses, or expenses on a Pending or Declined Travel Request, without revisiting this.
